# RoboCasa Docker image

Dockerfiles, builders, and launchers are maintained in [third_party/benchmarks/robocasa](../../../third_party/benchmarks/robocasa/README.md).

The image is `world/robocasa:1.0.1`, using Python 3.11 and MuJoCo 3.3.1. Isaac is not required. The agent policy and native action conversion remain in `environment/benchmarks/robocasa/`.
