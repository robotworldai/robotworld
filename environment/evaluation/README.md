# Evaluation suites

`suites.json` records selected tasks, official task mappings, instances, and asset entry points. `runner.py` invokes the benchmark launchers; it does not replace their controllers or success criteria.

Use the [batch evaluation guide](../../scripts/ROLLOUTS.md) for repeated trials and [model configuration](../../docs/MODELS.md) for providers. Lower-level diagnostics are described in [scripts/eval](../../scripts/eval/README.md).
